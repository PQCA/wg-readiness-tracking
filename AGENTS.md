## Project Overview
The readiness working group maintain a series of markdown documents that track whether various hardware and software support standardized Post-Quantum Cryptography ciphers for key encapsulation and signing. 

## Build and Test Commands
N/A - currently there are not formal build or test commands for contributors, but the prevailing style and formatting should be followed.

## Code Style & Architecture Guidelines
* Always follow existing style and formatting.
* Link to technical sources that validate the information provided whenever possible.
* Ensure that PR descriptions include a note that an agent was used to assist with PR creation.

## Critical Boundaries (What NOT to do)
* NEVER submit proprietary information, all submissions must contain public information that is verifiable using public sources.
* NEVER fabricate information to complete missing details
